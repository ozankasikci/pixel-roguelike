# Quick Task 260402-3o3 Summary

**One-liner:** Added "Create Group" to outliner right-click menu — groups selected objects at their centroid with undo/redo support.

## What Was Done

Added a "Create Group" context menu item to the outliner right-click popup in `EditorOutlinerPanel.cpp`. When clicked with one or more objects selected:

1. Captures undo state via `document.captureState()`
2. Computes the centroid of all selected objects' world positions using `document.worldTransformMatrix(selId)[3]`
3. Creates a `LevelGroupNode` at the centroid via `document.addGroup()`
4. Reparents each selected object under the group via `document.setParent()` (which internally preserves world transforms)
5. Pushes an undo command via `commandStack.pushDocumentStateCommand()`
6. Updates `selectedIds` to the new group

A separator visually separates "Create Group" from the "Delete" / "Clear Parent" items above.
