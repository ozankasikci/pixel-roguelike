In the `BeginPopupContextItem("OutlinerContext")` block (line 203), add a "Create Group" menu item after the existing "Clear Parent" item and before `ImGui::EndPopup()`. The item should be enabled when `selectedIds` is not empty (`!selectedIds.empty()`).

When clicked, the algorithm is:

1. **Capture undo state:** `const EditorSceneDocumentState beforeState = document.captureState();`

2. **Compute centroid** of all selected objects' world positions:
   ```cpp
   glm::vec3 centroid(0.0f);
   for (const auto selId : selectedIds) {
       centroid += glm::vec3(document.worldTransformMatrix(selId)[3]);
   }
   centroid /= static_cast<float>(selectedIds.size());
   ```

3. **Create group node** at centroid:
   ```cpp
   LevelGroupNode group;
   group.name = "Group";
   group.position = centroid;
   const std::uint64_t groupId = document.addGroup(group);
   ```

4. **Reparent each selected object** under the new group. `setParent` already internally captures the child's world transform and calls `applyWorldTransform` to preserve it, so a simple loop suffices:
   ```cpp
   for (const auto selId : selectedIds) {
       document.setParent(selId, groupId);
   }
   ```

5. **Push undo command:**
   ```cpp
   commandStack.pushDocumentStateCommand("Create Group", beforeState, document.captureState(), document);
   ```

6. **Update selection** to the new group:
   ```cpp
   selectedIds = {groupId};
   ui.inspectorContext = EditorInspectorContext::SceneSelection;
   ```

Place the menu item with a separator before it to visually separate from Delete/Clear Parent:
```cpp
ImGui::Separator();
if (!selectedIds.empty() && ImGui::MenuItem("Create Group")) {
    // ... algorithm above
}
```

Note: The `selectedIds` vector is captured by reference in the `renderNode` lambda, so modifications to it are visible. The right-click handler on line 143 already ensures the clicked object is selected if it was not, so `selectedIds` will always contain at least the right-clicked object.
