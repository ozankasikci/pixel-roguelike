# Quick Task 260406-pe8: Fix sky texture loading in packaged builds

## Problem

`SkyTextureLibrary::resolve()` and `SkyTextureLibrary::resolveCube()` pass raw relative paths (e.g. `assets/skies/clouds_soft.tga`) directly to `Texture2D::createRGBA8FromFile()` / `TextureCube::createRGBA8FromFiles()`, which call `stbi_load()` with the unresolved path. Other asset loaders (MeshLibrary, Shader, ContentRegistry) use `resolveProjectPath()` to handle CWD differences in packaged builds.

## Task 1: Add resolveProjectPath to SkyTextureLibrary

**Files:** `src/engine/rendering/post/SkyTextureLibrary.cpp`

**Action:**
1. Add `#include "engine/core/PathUtils.h"` at the top
2. In `resolve()` (line ~120): resolve the path before calling `createRGBA8FromFile`
3. In `resolveCube()` (line ~163): resolve each face path before calling `createRGBA8FromFiles`

**Verify:** Build compiles. Packaged game loads sky textures without warnings.

**Done:** Sky textures load correctly in packaged builds launched from any CWD.
