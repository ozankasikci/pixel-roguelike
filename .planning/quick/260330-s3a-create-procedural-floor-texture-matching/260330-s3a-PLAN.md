**Step 3 — Implement generateFloorPixels() in MaterialTextureLibrary.cpp:**

The floor texture should evoke Stanley Parable-style clean institutional flooring — warm beige/tan linoleum or polished tile. Think: clean office hallway floor, not dramatic tile patterns.

Use the standard two-pass pattern from the skill. Key characteristics:

- **ALL noise must be tileable** — use `tileableFbm` and `tileableValueNoise` exclusively (world_projected UV mode).
- **Base color:** Warm beige/tan — base around `glm::vec3(0.88f, 0.84f, 0.76f)` with a slightly cooler variant `glm::vec3(0.84f, 0.82f, 0.77f)`. These are institutional floor tones — warmer and slightly more yellow-shifted than the smooth wall texture.
- **Subtle large-scale tile grid (optional soft tiles):** Use `smooth01` to create very faint seam lines suggesting large floor tiles (e.g., 4x4 grid within the UV space). Seams should be barely visible — just a slight color darkening (multiply by ~0.97) and slight height depression (height -= 0.003). This is NOT a heavy grout line — it is the barely-visible join between polished linoleum sheets or large format tiles.
- **Surface variation:** 3 tileable fBm layers with different seeds and frequencies:
  - Broad warm/cool shift: `tileableFbm(p, 2.0f, seed1)` — drives base color blend
  - Mid-frequency subtle mottling: `tileableFbm(p, 6.0f, seed2)` — slight color modulation (*= 0.97 + mid * 0.04)
  - Fine micro-grain: `tileableFbm(p, 20.0f, seed3)` — very subtle grain pattern
  - Use unique seeds distinct from smooth wall (e.g., `glm::vec2(13.7f, 2.9f)`, `glm::vec2(6.3f, 18.1f)`, `glm::vec2(9.8f, 3.4f)`)
- **Slight warm specular spots:** Add a 4th tileable noise layer at low frequency that slightly reduces roughness in patches — simulating the slight sheen variation of polished linoleum.
- **Height field:** Very subtle, similar to smooth wall — `(mid - 0.5f) * 0.003f + (fine - 0.5f) * 0.001f` plus the faint seam depressions.
- **Roughness:** 0.45-0.65 range — notably lower/glossier than walls (0.68-0.78) to convey a polished/waxed floor surface. The Stanley Parable floors have a slight sheen.
- **AO:** 0.96-1.0 for open surface, dropping to ~0.90 at seam lines.
- **Albedo range:** Stay within 0.72-0.92 — warm, muted, never saturated.
