<objective>
Fix the lighting attenuation function to use physically-based 1/r^2 inverse-square falloff, rescale all light intensities to compensate, fix specular spike floor, and tune exposure.

Purpose: The current attenuation() function only uses a quartic window (smooth radius cutoff) but lacks the 1/r^2 distance term. This means lights deliver near-100% intensity across most of their radius, causing overbright scenes when multiple lights overlap. The ACES tonemapper receives values of 5-50 instead of 0.5-2.0, compressing everything to white.

Output: Correctly attenuated lighting across all scenes with balanced brightness.
</objective>

<task type="auto">
  <name>Task 1: Fix attenuation function and specular denominator in scene.frag</name>
  <files>assets/shaders/game/scene.frag</files>
  <action>
Two changes in assets/shaders/game/scene.frag:

**1. Fix attenuation() at line 72-75:**
Replace the current function:
```glsl
float attenuation(float dist, float radius) {
    float x = clamp(1.0 - pow(dist / max(radius, 0.001), 4.0), 0.0, 1.0);
    return x * x;
}
```
With inverse-square plus window:
```glsl
float attenuation(float dist, float radius) {
    float x = clamp(1.0 - pow(dist / max(radius, 0.001), 4.0), 0.0, 1.0);
    float window = x * x;
    float invSq = 1.0 / (dist * dist + 0.01);
    return window * invSq;
}
```
The `window` term provides smooth cutoff at `radius`. The `invSq` term provides physically-based 1/r^2 falloff. The 0.01 epsilon prevents division-by-zero at dist=0 and caps max attenuation at 100 (at dist=0, invSq=100).

**2. Raise specular denominator floor at line 726:**
Change:
```glsl
vec3 specular = (D * G * F) / max(4.0 * NdotV * NdotL, 0.001);
```
To:
```glsl
vec3 specular = (D * G * F) / max(4.0 * NdotV * NdotL, 0.01);
```
This raises the floor from 0.001 to 0.01, capping specular at 100x instead of 1000x, preventing extreme spikes on Metal materials at grazing angles.
