<objective>
Add `EditorSceneObjectKind::Group` with `LevelGroupNode` payload for hierarchy grouping in the level editor.

Purpose: Enable authors to organize objects under named empty group nodes (the universal industry pattern from Unity/Godot) instead of abusing mesh objects as parents. Group nodes carry transforms for child inheritance but produce no ECS entities at runtime.

Output: Full round-trip support for group nodes — data struct, serialization, editor document operations, outliner UI button, inspector transform editing, and preview world handling.
</objective>

   - Add `Group` to the `LevelNodeRef::Kind` enum (inside the anonymous namespace)

   - Loop over `data.groups` and push `LevelNodeRef` entries (same pattern as meshes/lights/etc)
   - Add `localMatrixFor` case for `Kind::Group`: `makeTransformMatrix(placement.position, placement.rotation, placement.scale)`
