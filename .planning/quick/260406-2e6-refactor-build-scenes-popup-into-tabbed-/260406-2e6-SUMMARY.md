# Quick 260406-2e6: Refactor Build Scenes Popup into Tabbed Build Settings Window Summary

**One-liner:** Replaced the "Build Scenes" popup modal with a tabbed "Build Settings" window using ImGui BeginTabBar, with "Scenes" as the first tab and Close outside the tab bar.

## What Was Built

The editor's Build menu item "Build Scenes..." was renamed to "Build Settings..." and its popup modal was refactored into a tabbed window. The scene selection UI (All Scenes checkbox, per-scene checkboxes, Select All button, summary text) is unchanged and lives inside a "Scenes" tab. The Close button sits below the tab bar so it applies to the whole window regardless of which tab is active.

## Changes Made

### apps/level_editor/main.cpp
- Renamed `buildScenesPopupRequested` flag to `buildSettingsPopupRequested` (declaration + all 3 use sites)
- Changed menu item label from `"Build Scenes..."` to `"Build Settings..."`
- Replaced `BeginPopupModal("Build Scenes", ...)` with `BeginPopupModal("Build Settings", ...)`
- Wrapped scene selection UI in `BeginTabBar("BuildSettingsTabs")` / `BeginTabItem("Scenes")`
- Moved the `Close` button after `EndTabBar()` so it applies to the whole window
- Widened `SetNextWindowSize` from `350.0f` to `400.0f` to accommodate tab bar
- Added comments showing where future `Graphics` and `Platform` tabs would be inserted
