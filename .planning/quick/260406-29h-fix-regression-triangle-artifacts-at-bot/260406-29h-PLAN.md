# Quick Plan: Fix CSM shadow triangle artifacts at wall-floor junctions

## Context

The shadow caster offset (0.18 units toward light) in shadow_depth.vert was added in commit b0a35fa to fix white line artifacts at wall-ceiling edges. This offset pushes ALL shadow geometry upward toward the sun during the CSM pass. While it closes gaps at ceiling junctions, it creates gaps at floor junctions — visible as bright triangle artifacts at the bottom of walls from the first-person play view camera.

## Root Cause

The uniform caster offset is directionally biased: it extends shadow coverage above geometry edges but reduces it below. At the wall-floor junction, the wall's shadow map coverage starts 0.18 units above the actual floor level, creating a gap where light leaks through in triangle shapes following the mesh tessellation.

## Fix Strategy

Replace the caster-side offset with a receiver-side normal offset in the fragment shader. Each surface's shadow lookup position shifts along its own geometric normal, scaled by the grazing angle to the light. This closes gaps at ALL junction types (floor-wall, wall-ceiling, wall-wall) symmetrically.

## Task 1: Add receiver-side normal offset in scene.frag

**Files:** `assets/shaders/game/scene.frag`
**Action:** In `sampleCsmShadow()`, compute a normal-based position offset and use it for CSM projection instead of raw `fragWorldPos`.

The offset formula:
```glsl
float NdotL = dot(N, L);
float slopeFactor = sqrt(1.0 - clamp(NdotL * NdotL, 0.0, 1.0));
vec3 biasedWorldPos = fragWorldPos + N * 0.15 * slopeFactor;
```

Apply `biasedWorldPos` to:
1. The initial `computeCsmProjection()` call (line ~867)
2. The cascade blend `nextLightSpace` projection (line ~908)

**Verify:** Shader compiles (build succeeds).
**Done:** `sampleCsmShadow` uses normal-biased world position for all CSM lookups.

## Task 2: Remove caster-side offset for CSM pass

**Files:** `src/engine/rendering/SceneRenderPipeline.cpp`
**Action:** In the CSM section (~line 218-219), set `uShadowCasterOffset` to 0.0f (same as spot lights). The receiver-side normal offset in the fragment shader now handles junction gaps. Keep the `uLightDirection` uniform set (no harm, and useful if the offset is ever re-enabled for tuning).

Change:
```cpp
shadowShader_->setFloat("uShadowCasterOffset", 0.18f);
```
To:
```cpp
shadowShader_->setFloat("uShadowCasterOffset", 0.0f);
```

Update the comment to explain the change.

**Verify:** Build succeeds.
**Done:** CSM pass no longer applies a directional caster offset.
