# Quick Task 260406-29h: Fix CSM Shadow Triangle Artifacts at Wall-Floor Junctions

Replaced directional caster-side shadow offset with a symmetric receiver-side normal offset in the CSM shadow sampling path, eliminating triangle artifacts at wall-floor junctions while preserving wall-ceiling gap coverage.

## Changes Made

### Task 1: Add receiver-side normal offset in scene.frag (863b242)

Added a normal-based world-position bias to `sampleCsmShadow()` that shifts the shadow lookup position along the surface normal before cascade projection. The bias magnitude scales with `sin(angle)` between the normal and light direction -- maximum at grazing angles where junction gaps appear, zero when the surface faces the light directly. Applied the biased position to both the primary cascade lookup and the cascade blend lookup.

**Files modified:** `assets/shaders/game/scene.frag`

### Task 2: Disable caster-side offset in SceneRenderPipeline.cpp (ade6828)

Set `uShadowCasterOffset` to `0.0f` (was `0.18f`) in the CSM shadow pass. The caster offset pushed geometry toward the light uniformly, which fixed wall-ceiling gaps but introduced a directional bias that created triangle artifacts at wall-floor junctions in first-person view. With the receiver-side approach handling gaps symmetrically, the caster offset is no longer needed.

**Files modified:** `src/engine/rendering/SceneRenderPipeline.cpp`
