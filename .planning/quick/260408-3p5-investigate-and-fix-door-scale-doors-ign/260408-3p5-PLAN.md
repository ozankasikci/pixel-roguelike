<objective>
Add scale support to door groups so that editing a door group's scale in the editor
actually changes the rendered size of the door. Currently LevelDoorPlacement has no
scale field -- the entire door pipeline (data model, parser, serializer, spawner,
hierarchy resolution, editor inspector) ignores scale.

Purpose: Door groups are the only entity type in the scene format that cannot be scaled,
which is a significant editor workflow gap.

Output: Door groups support a vec3 scale that persists through save/load, applies to
leaf mesh rendering, and is editable in the inspector.
</objective>
