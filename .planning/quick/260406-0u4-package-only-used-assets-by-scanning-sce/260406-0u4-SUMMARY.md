## Decisions Made
- Built-in procedural meshes (plane, cube, sphere, cylinder, quad, cone, hemisphere) are excluded from unresolved mesh ID warnings since they are generated at runtime
- Environment files are scanned in both `assets/defs/environments/` and `assets/environments/` to match the project's dual-directory structure
- Prefab scanning is recursive to catch prefabs in subdirectories (e.g. `assets/prefabs/gameplay/`)
- Def file scanning covers .weapon, .enemy, .item, and .skill extensions
