```cpp
/// Collected set of asset file paths that are actually referenced by game content.
struct AssetManifest {
    std::set<std::string> texturePaths;  // e.g. "assets/packs/.../T_Wall_BaseColor.png"
    std::set<std::string> skyPaths;      // e.g. "assets/skies/.../px.png"
    std::set<std::string> meshFiles;     // e.g. "assets/packs/.../SM_Wall.fbx"
};

/// Scan scene/material/environment/prefab/def files to build a manifest of referenced assets.
AssetManifest collectUsedAssets();
```

Add `#include <set>` to the header.

**In EditorBuildSystem.cpp**, implement `collectUsedAssets()` and rewrite `packageGame()`:

**collectUsedAssets() implementation** (new function, add before packageGame):

1. **Collect texture paths from material files:**
   - Iterate all `.material` files in `assets/materials/` using `fs::directory_iterator`
   - For each file, read line by line with `std::ifstream` + `std::getline`
   - If a line starts with `albedo_map`, `normal_map`, `roughness_map`, or `ao_map`, extract the second whitespace-delimited token (the file path)
   - Insert into `manifest.texturePaths`

2. **Collect sky/cloud asset paths from environment files:**
   - Scan both `assets/defs/environments/` and `assets/environments/` for `.environment` files
   - For each file, read line by line
   - For `sky_cubemap_faces` lines: extract tokens 1-6 (6 face paths) and insert all into `manifest.skyPaths`
   - For `sky_cloud_layer_a`, `sky_cloud_layer_b`, `sky_panorama_path`, `sky_horizon_layer` lines: extract the single path token and insert into `manifest.skyPaths`

3. **Collect mesh IDs from scene files:**
   - Build a `std::set<std::string> neededMeshIds`
   - Iterate all `.scene` files in `assets/scenes/`
   - For each file, read line by line. For lines starting with `mesh `, extract the second token (the mesh ID). Insert into `neededMeshIds`

4. **Collect mesh IDs from prefab files:**
   - Recursively scan `assets/prefabs/` for `.prefab` files
   - For each file, read line by line
   - If a line starts with `left_leaf_mesh`, `right_leaf_mesh`, or just `mesh `, extract the value token and insert into `neededMeshIds`

5. **Collect mesh IDs from def files:**
   - Recursively scan `assets/defs/` for `.weapon`, `.enemy`, `.item`, `.skill` files
   - For lines starting with `mesh `, extract the value and insert into `neededMeshIds`

6. **Resolve mesh IDs to file paths:**
   - Use `ModelLoader::discoverProjectAssets()` to scan `assets/meshes/` and `assets/packs/` (same as the runtime does)
   - For each discovered asset whose `meshId` is in `neededMeshIds`, add its `relativePath` to `manifest.meshFiles`
   - Log a warning for any mesh ID in `neededMeshIds` that was not found (typo or missing asset)

Return the manifest.

**packageGame() rewrite** (replace the `fs::copy("assets", ...)` block):

After copying the game binary (keep that code unchanged), replace the single `fs::copy("assets", ...)` call with:

```
a) Create the output assets directory: fs::create_directories(outputDir + "/assets")

b) Always-copy directories (small, all needed) — use fs::copy with recursive option:
   - assets/shaders/   -> outputDir/assets/shaders/
   - assets/defs/      -> outputDir/assets/defs/
   - assets/prefabs/   -> outputDir/assets/prefabs/
   - assets/materials/ -> outputDir/assets/materials/
   - assets/scenes/    -> outputDir/assets/scenes/
   - assets/fonts/     -> outputDir/assets/fonts/
   For each: check if source exists before copying (skip gracefully if not)

c) Also copy environments directories if they exist:
   - assets/environments/ -> outputDir/assets/environments/

d) Copy project.cfg:
   - assets/project.cfg -> outputDir/assets/project.cfg (if exists)

e) Call collectUsedAssets() to get the manifest

f) For each path in manifest.texturePaths + manifest.skyPaths + manifest.meshFiles:
   - Compute dest = fs::path(outputDir) / path
   - fs::create_directories(dest.parent_path())
   - fs::copy_file(path, dest, fs::copy_options::overwrite_existing)
   - Increment a file counter and accumulate size via fs::file_size()
   - Wrap in try/catch per-file; log warning and continue if a referenced file is missing

g) After all copies, compute total package size (recursive scan of outputDir)
   Log: "Package created: {N} referenced assets ({X} MB) — saved {Y} MB vs full copy"
   Add the same info to BuildOutputLog
```

**Important implementation details:**
- Use `std::istringstream` to tokenize lines (handles multiple spaces cleanly)
- All file paths in material/environment files are relative to the project root (e.g. `assets/packs/...`), so they can be used directly with `fs::copy_file` assuming cwd is project root
- The existing `resolveProjectPath()` function is NOT available in EditorBuildSystem — use paths relative to cwd (same as the existing `fs::copy("assets", ...)` does)
- Keep the Windows stub for `packageGame` unchanged (it already returns false with a warning)
- Add `#include <set>` and `#include <sstream>` to the .cpp includes
- Do NOT include ModelLoader.h in the header — include it only in the .cpp file to avoid coupling the header to engine internals
