In `updateRuntimeDoorAnimation()` (line ~490), replace the early continue for non-opening, non-opened doors
with an InteractableComponent reset before continuing. This matches the pattern already used by
`DoorAnimationSystem::update()` at lines 105-108.

Change lines 490-492 from:
```cpp
if (!door.opening && !door.opened) {
    continue;
}
```

To:
```cpp
if (!door.opening && !door.opened) {
    if (auto* ic = registry.try_get<InteractableComponent>(entity)) {
        ic->busy = false;
        ic->enabled = true;
    }
    continue;
}
```

This ensures that after `restoreBaselineState()` resets a door to closed, the very next frame
tick will restore the InteractableComponent to enabled, making the "Press E to open" prompt
visible again.
