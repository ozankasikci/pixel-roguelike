**1. Add missing include (around line 52, after `#include <cstdint>`):**

**2. Fix Build Settings window sizing (line 978):**
Change:
```cpp
ImGui::SetNextWindowSize(ImVec2(400.0f, 0.0f), ImGuiCond_Appearing);
```
To:
```cpp
ImGui::SetNextWindowSize(ImVec2(400.0f, 350.0f), ImGuiCond_Appearing);
```
This gives the modal a sensible initial height. `ImGuiCond_Appearing` means it only applies on first open, and `AlwaysAutoResize` on line 981 will still allow the window to grow if content exceeds this — but it will not shrink below the content size. The key fix is not starting from height 0.

**3. Add openFolderInOS helper and two UI insertion points:**

a) Add a static helper function in the anonymous namespace area near the top of the file (find an appropriate location before the main function, or at the top of the main function's scope near other local helpers). Follow the same pattern as `revealInFinder` in EditorAssetBrowserPanel.cpp but open a directory instead of revealing a file:
```cpp
namespace {
void openFolderInOS(const std::string& path) {
#ifdef __APPLE__

#elif defined(_WIN32)

#else
    std::string cmd = "xdg-open \"" + path + "\" &";

}
} // namespace
```
Note: Use `open` (not `open -R`) since we're opening a folder, not revealing a file.
