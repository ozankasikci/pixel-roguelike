       ```
       sips -z 2048 2048 assets/textures/smooth_concrete_wall_uhnlfbvn_8k/Smooth_Concrete_Wall_uhnlfbvn_8K_AO.jpg --out assets/textures/smooth_concrete_wall_uhnlfbvn_2k/Smooth_Concrete_Wall_uhnlfbvn_2K_AO.jpg
       ```

    3. Create `assets/defs/materials/concrete_wall.material` with this exact content:
       ```
       id concrete_wall
       parent masonry_base
       shading_model stone
       albedo_map assets/textures/smooth_concrete_wall_uhnlfbvn_2k/Smooth_Concrete_Wall_uhnlfbvn_2K_BaseColor.jpg
       normal_map assets/textures/smooth_concrete_wall_uhnlfbvn_2k/Smooth_Concrete_Wall_uhnlfbvn_2K_Normal.jpg
       roughness_map assets/textures/smooth_concrete_wall_uhnlfbvn_2k/Smooth_Concrete_Wall_uhnlfbvn_2K_Roughness.jpg
       ao_map assets/textures/smooth_concrete_wall_uhnlfbvn_2k/Smooth_Concrete_Wall_uhnlfbvn_2K_AO.jpg
       uv_mode world_projected
       uv_scale 0.5 0.5
       normal_strength 0.5
       roughness_scale 1.0
       roughness_bias 0.0
       ao_strength 0.8
       light_tint_response 0.08
       ```

       Key choices:
       - `parent masonry_base` inherits base masonry defaults (metalness 0, base_color white)
       - `shading_model stone` matches the stone MaterialKind used for concrete walls
       - `uv_mode world_projected` ensures seamless tiling across wall panels without UV seams
       - `uv_scale 0.5 0.5` provides reasonable tile density for 2m wall panels
       - `normal_strength 0.5` is moderate -- not too bumpy for the clean Stanley Parable aesthetic
       - `ao_strength 0.8` provides subtle depth without heavy shadowing
       - No `procedural_source` line -- this is a file-based material, the MaterialTextureLibrary will use createRGBA8FromFile/createR8FromFile paths automatically
  </action>
