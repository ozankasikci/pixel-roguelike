# Quick Task 260405-587: Single-click to enter text edit on DragFloat fields

## Summary

Enabled `io.ConfigDragClickToInputText = true` in ImGuiLayer::init(). This is a built-in ImGui beta flag that makes DragFloat/DragInt widgets enter text input mode on a simple click-release (without dragging), instead of requiring a double-click.

## Changes

| File | Change |
|------|--------|
| `src/engine/ui/ImGuiLayer.cpp` | Added `io.ConfigDragClickToInputText = true` after `ConfigFlags` setup |

## Behavior

- **Click and release** on a DragFloat value → enters text input mode (type a number)
- **Click and drag** on a DragFloat value → adjusts value by dragging (unchanged)
- **Double-click** still works as before (also enters text input)
