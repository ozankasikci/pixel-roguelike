**Step 2: Add a sourceSnippet helper (near shaderSnippet, around line 442)**

Add a `scriptSourceSnippet` function near `shaderSnippet`. It should read up to 30 lines from the script's `sourcePath` (which is a relative path like `assets/scripts/foo.ts`). Reuse the same pattern as `shaderSnippet` but with a 30-line limit:

```cpp
std::string scriptSourceSnippet(const std::string& sourcePath) {
    std::ifstream file(sourcePath);
    if (!file.is_open()) {
        return {};
    }
    std::ostringstream snippet;
    std::string line;
    int lineCount = 0;
    while (std::getline(file, line) && lineCount < 30) {
        snippet << line << '\n';
        ++lineCount;
    }
    return snippet.str();
}
```
