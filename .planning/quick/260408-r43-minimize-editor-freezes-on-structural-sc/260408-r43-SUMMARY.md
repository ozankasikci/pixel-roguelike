# Phase quick Plan 260408-r43: Minimize Editor Freezes on Structural Scene Changes — Summary

**One-liner:** Incremental ECS entity add/remove on object count change + guarded texture reload skip eliminates two freeze sources when adding/removing scene objects in the level editor.

## What Was Built

Three freeze sources on structural scene changes (object add/remove) were eliminated:

**1. Incremental EditorPreviewWorld (Task 1)**

`EditorPreviewWorld` gained a `objectEntities_` reverse map (`std::unordered_map<std::uint64_t, std::vector<entt::entity>>`), populated during `rebuild()` alongside the existing `ownerMap_`. The per-object spawn logic was extracted from the monolithic `rebuild()` switch-case into a private `spawnObject()` helper. Two new public methods were added:

- `addObjects(objectIds, document, content)` — spawns only the new objects by calling `spawnObject()` per id, updates both maps, then calls `rebuildBounds()`.
- `removeObjects(objectIds)` — destroys only the affected ECS entities, erases them from `ownerMap_`, `objectEntities_`, and `objectBounds_`, then recomputes `sceneBounds_` inline from the remaining `objectBounds_` entries.

**2. Incremental wiring in main.cpp (Task 2)**

The `document.objects().size() != previewObjectCount` branch in the scene sync loop was replaced with a diff-based incremental path: it builds `docIds` and `worldIds` sets, computes `toAdd`/`toRemove` vectors, and calls `previewWorld.addObjects`/`removeObjects` on only the delta. No full `previewWorld.rebuild()` is triggered.

**3. Removed 200ms auto-rebuild timer (Task 2)**

The entire `if (!ui.playPreview && runtimePreviewDirtyState == FullWorldRebuild && runtimePreviewAutoRebuildPending && ...)` block was deleted. `runtimePreviewAutoRebuildPending` and `lastRuntimePreviewStructuralChangeTime` variables were removed from the file entirely. Runtime session rebuilds now happen only at play-press.

**4. Guarded texture cache wipe (Task 2)**

`RuntimeGameSession::rebuild()` gained a `bool contentChanged = false` parameter. `renderer_.reloadContent(content)` is now gated on `rendererInitialized_ && contentChanged`. Since the default is false, all existing call sites (play-press, reset-start) automatically skip the texture cache wipe. `EditorRuntimePreviewSession::rebuild()` forwards the parameter.
