<objective>
Wire PlayerTorchOverride into the level editor as the source of truth for torch lighting parameters.

Purpose: Currently PlayerTorchOverride lives only in RuntimeLightingOverride (game-layer debug struct) and is adjustable only via the runtime debug overlay. It is not part of LightingEnvironment, so torch settings cannot be edited in the editor's Environment panel or persisted to .env definition files. This breaks the source-of-truth chain that works correctly for Sun/Fill/Hemisphere lighting.

Output: PlayerTorchOverride moved to engine-layer RenderLight.h, added to LightingEnvironment, serialized in environment definition files, synced to RuntimeLightingOverride, and editable in the editor Environment panel with full undo support.
</objective>
