## How to set the pivot precisely
The `pivot` field is in **mesh-local coordinates** — it's the point in the door mesh's own coordinate system around which the door rotates. To find the correct value:
1. Select the door group in the editor
2. Check the leaf mesh's pivot field in the inspector
3. Drag the values while watching the magenta hinge marker move in the viewport
4. The hinge marker should align with the physical hinge edge of the door model
