# Quick Task 260406-v67: Fix door leaf moving when hinge pivot is changed

## What Changed

**EditorPreviewWorld.cpp** — Both `rebuild()` and `syncTransforms()` leaf branches now build the model matrix as:

```
T(hingeWorldPos) * R(yaw) * T(-hingePivot) * S(kDoorScale)
```

Instead of the previous:

```
T(hingeWorldPos) * R(yaw) * S(kDoorScale)
```

The `-hingePivot` translation cancels out the pivot offset, keeping the mesh center at `rootPosition` regardless of the pivot value. Changing the hinge pivot in the inspector no longer moves the door visually — it only affects the rotation center.
