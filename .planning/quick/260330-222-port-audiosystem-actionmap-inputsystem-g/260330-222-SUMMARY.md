## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] OpenAL Soft include paths on macOS**
- **Found during:** Build verification
- **Issue:** `find_package(OpenAL)` found macOS system framework using `<OpenAL/al.h>`, but AudioSystem.cpp uses `<AL/al.h>` (Homebrew openal-soft convention)
- **Fix:** Added `OPENAL_INCLUDE_DIR` and `OPENAL_LIBRARY` cache hints pointing to `/opt/homebrew/opt/openal-soft` in top-level CMakeLists.txt; used `${OPENAL_INCLUDE_DIR}` and `${OPENAL_LIBRARY}` directly in engine_audio target
- **Files modified:** `CMakeLists.txt`, `src/engine/CMakeLists.txt`
- **Commit:** ecc270a

**2. [Rule 3 - Blocking] Torch cone debug params removed from DebugParams**
- **Found during:** Build verification
- **Issue:** Removing `playerTorchInnerConeDegrees` / `playerTorchOuterConeDegrees` from `DebugParams` broke `RuntimeSceneRenderer.cpp` which referenced them
- **Fix:** Added `constexpr float kPlayerTorchInnerConeDegrees = 58.0f` and `kPlayerTorchOuterConeDegrees = 82.0f` as file-scope constants in RuntimeSceneRenderer.cpp (same values as the removed defaults)
- **Files modified:** `src/game/rendering/RuntimeSceneRenderer.cpp`
- **Commit:** ecc270a

**3. [Rule 3 - Blocking] Level editor still called removed ImGuiLayer methods**
- **Found during:** Build verification
- **Issue:** `apps/level_editor/main.cpp` called `ImGuiLayer::renderInventory()` and `ImGuiLayer::renderInteractionPrompt()` which were moved to `GameOverlays`
- **Fix:** Added `#include "game/ui/GameOverlays.h"` and replaced `ImGuiLayer::` calls with `GameOverlays::`
- **Files modified:** `apps/level_editor/main.cpp`
- **Commit:** ecc270a

**4. [Rule 3 - Blocking] Test still used RuntimeInputState**
- **Found during:** Build verification
- **Issue:** `tests/game/test_runtime_game_session.cpp` used `RuntimeInputState` type directly
- **Fix:** Changed to `InputSystem` with matching include
- **Files modified:** `tests/game/test_runtime_game_session.cpp`
- **Commit:** ecc270a

**5. [Rule 3 - Blocking] Editor preview session used RuntimeInputState types**
- **Found during:** Feature 3 migration (proactive)
- **Issue:** `EditorRuntimePreviewSession.h/cpp` used `RuntimeInputState&` and `RuntimeInputState::MaxKeys`/`MaxButtons` constants
- **Fix:** Changed to `InputSystem&` and `InputSystem::kMaxKeys`/`kMaxButtons`
- **Files modified:** `src/editor/core/EditorRuntimePreviewSession.h`, `src/editor/core/EditorRuntimePreviewSession.cpp`
- **Commit:** dfb8407
