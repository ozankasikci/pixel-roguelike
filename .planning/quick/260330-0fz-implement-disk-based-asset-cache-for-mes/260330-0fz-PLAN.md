Output: `AssetCache` class, modified `Mesh` with pre-interleaved constructor, integrated cache lookups in `MeshLibrary` and `MaterialTextureLibrary`.

Create `.cache/meshes/` directory if not exists.
    - `static std::optional<CachedTextureData> findTextureCache(const std::string& name, uint64_t paramHash)` -- look up `.cache/textures/{name}_{hash hex}.tex.bin`, validate header param_hash matches, return data or nullopt.
    - `static void writeTextureCache(const std::string& name, uint64_t paramHash, const std::vector<uint8_t>& pixels, uint16_t width, uint16_t height, uint8_t channels)` -- write header + pixel data. Create `.cache/textures/` directory if not exists.
    - `static uint64_t hashFileContents(const std::string& filepath)` -- read file into memory, run FNV-1a 64-bit.
    - `static uint64_t hashBytes(const void* data, size_t length)` -- FNV-1a 64-bit implementation.

    **Binary format per design doc:**

    Mesh header (32 bytes): magic "MSH\0" (4), version 1 (1), padding (3), content_hash (8), vertex_count (4), index_count (4), aabb_min (12), aabb_max (12). Total = 48 bytes. NOTE: The design doc says 32 bytes for the first part but there is 48 bytes of data including AABB -- adjust padding/layout so the header is a clean struct. Define as a packed struct with `#pragma pack(push, 1)`. The total header should be:
    - magic: 4 bytes
    - version: 1 byte
    - padding: 3 bytes
    - content_hash: 8 bytes
    - vertex_count: 4 bytes (uint32_t)
    - index_count: 4 bytes (uint32_t)
    - aabb_min: 12 bytes (3x float)
    - aabb_max: 12 bytes (3x float)
    Total: 48 bytes.

    Texture header (24 bytes): magic "TEX\0" (4), version 1 (1), padding (1), width (2 uint16), height (2 uint16), channels (1), padding (1), param_hash (8), reserved (4). Total: 24 bytes.

    On `findMeshCache`: open file, read header, check magic == "MSH\0" and version == 1. Recompute hash of source file. If header hash != computed hash, return nullopt (stale). Read vertex data (vertex_count * 11 * sizeof(float) bytes) and index data (index_count * sizeof(uint32_t) bytes). Return CachedMeshData.

    On `writeMeshCache`: derive vertex_count from interleavedVertices.size() / 11, index_count from indices.size(). Fill header, write header + data.

    On `findTextureCache`: open `.cache/textures/{name}_{hash hex}.tex.bin`, read header, check magic == "TEX\0" and version == 1, check param_hash matches. Read pixels. Return CachedTextureData.

    **FNV-1a 64-bit:**
    ```
    offset_basis = 14695981039346656037ULL
    prime = 1099511628211ULL
    for each byte: hash ^= byte; hash *= prime
    ```

    Use `std::filesystem::create_directories` for cache dir creation. Use `std::ifstream`/`std::ofstream` in binary mode for I/O. Log cache hits/misses with spdlog at info level: "AssetCache: mesh cache hit for '{name}'" / "AssetCache: mesh cache miss for '{name}'".

    The cache root should be determined relative to the project root. Use the same approach as `resolveProjectPath` -- use `std::filesystem::current_path()` and walk up to find the project root (where `assets/` exists), then place `.cache/` there. Alternatively, since the game always runs from the project root or build dir, just use `.cache/` relative to cwd and let `resolveProjectPath` do the probing.

    **1. Modify `MeshLibrary::loadFromFile()` in MeshLibrary.cpp:**

    Add `#include "engine/rendering/assets/AssetCache.h"` at the top.

    Change the implementation to:
    ```
    void MeshLibrary::loadFromFile(const std::string& name, const std::string& filepath) {
        std::string resolvedPath = resolveProjectPath(filepath);

        // Try disk cache first
        auto cached = AssetCache::findMeshCache(resolvedPath);
        if (cached) {
            registerMesh(name, std::make_unique<Mesh>(
                cached->interleavedVertices, cached->indices,
                cached->aabbMin, cached->aabbMax));
            return;
        }

        // Cache miss: full load path
        RawMeshData raw = ModelLoader::loadRaw(resolvedPath);
        if (raw.positions.empty() || raw.indices.empty()) {
            spdlog::error("MeshLibrary: failed to load mesh '{}' from '{}'", name, filepath);
            return;
        }

        // Create mesh (this interleaves the data)
        auto mesh = std::make_unique<Mesh>(raw.positions, raw.normals, raw.uvs, raw.tangents, raw.indices);

        // Write to cache for next time -- interleave data again for cache storage
        // (Mesh constructor already computed AABB; we need the interleaved data)
        std::vector<float> interleaved;
        interleaved.reserve(raw.positions.size() * 11);
        for (size_t i = 0; i < raw.positions.size(); ++i) {
            interleaved.push_back(raw.positions[i].x);
            interleaved.push_back(raw.positions[i].y);
            interleaved.push_back(raw.positions[i].z);
            const auto& n = i < raw.normals.size() ? raw.normals[i] : glm::vec3(0,1,0);
            interleaved.push_back(n.x); interleaved.push_back(n.y); interleaved.push_back(n.z);
            const auto& uv = i < raw.uvs.size() ? raw.uvs[i] : glm::vec2(0,0);
            interleaved.push_back(uv.x); interleaved.push_back(uv.y);
            const auto& t = i < raw.tangents.size() ? raw.tangents[i] : glm::vec3(1,0,0);
            interleaved.push_back(t.x); interleaved.push_back(t.y); interleaved.push_back(t.z);
        }
        AssetCache::writeMeshCache(resolvedPath, interleaved, raw.indices, mesh->aabbMin(), mesh->aabbMax());

        registerMesh(name, std::move(mesh));
    }
    ```

    This replaces the current `ModelLoader::load()` call. The raw data is loaded via `ModelLoader::loadRaw()` instead so we have access to both the raw components (for creating the Mesh) and can produce interleaved data for the cache.

    **2. Modify `MaterialTextureLibrary` for procedural texture caching:**

    Add `#include "engine/rendering/assets/AssetCache.h"` to MaterialTextureLibrary.cpp.

    The texture cache key is the `textureKeyFor()` string hashed with FNV-1a. Each procedural texture set has 4 maps (albedo RGBA8, normal RGBA8, roughness R8, ao R8). Cache each map separately with a name suffix: `{key}_albedo`, `{key}_normal`, `{key}_roughness`, `{key}_ao`.

    Modify `ensureTextureSet()`:
    - After the existing in-memory cache check (which remains as-is), before calling `buildBrickSet`/`buildStoneSet`:
    - Compute `uint64_t paramHash = AssetCache::hashBytes(key.data(), key.size())`.
    - Try loading all 4 maps from disk cache: `AssetCache::findTextureCache(key + "_albedo", paramHash)`, etc.
    - If ALL 4 maps return data, create the TextureSet from cached pixels using `textures.albedo.createRGBA8(cached.width, cached.height, cached.pixels)` etc., emplace into `textureSets_`, and return early.
    - If any map is missing (cache miss), fall through to the existing generation path.
    - After generation (after `buildBrickSet`/`buildStoneSet` or file loading), write the generated pixel data to the texture cache.

    Option B: Add new private methods `generateBrickPixels`/`generateStonePixels` that return pixel data, then have buildBrickSet call those + create textures.

    if (resolved.proceduralSource == MaterialProceduralSource::GeneratedBrick ||
        resolved.proceduralSource == MaterialProceduralSource::GeneratedStone) {
        ProceduralPixelData pixels = (resolved.proceduralSource == MaterialProceduralSource::GeneratedBrick)

        textures.normal.createRGBA8(pixels.size, pixels.size, pixels.normal);
        textures.roughness.createR8(pixels.size, pixels.size, pixels.roughness);
        textures.ao.createR8(pixels.size, pixels.size, pixels.ao);
        // Write to disk cache
        uint16_t sz = static_cast<uint16_t>(pixels.size);
        AssetCache::writeTextureCache(key + "_albedo", paramHash, pixels.albedo, sz, sz, 4);
        AssetCache::writeTextureCache(key + "_normal", paramHash, pixels.normal, sz, sz, 4);
        AssetCache::writeTextureCache(key + "_roughness", paramHash, pixels.roughness, sz, sz, 1);
