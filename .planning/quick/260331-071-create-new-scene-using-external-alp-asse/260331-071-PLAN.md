Key patterns from existing codebase:

**Mesh registration** in `src/game/levels/GameAssets.cpp`:
```cpp
meshLibrary.registerFileAlias("pillar", "assets/meshes/pillar.glb");
```
File aliases are lazy-loaded by MeshLibrary::get() via ModelLoader::loadRaw() (Assimp). FBX is a supported format.

**Material definition format** (`.material` files in `assets/materials/`):
```
id material_id
base_color 1.0 1.0 1.0
uv_mode mesh
uv_scale 1.0 1.0
normal_strength 1.0
roughness_scale 1.0
roughness_bias 0.74
metalness 0.0
ao_strength 1.0
albedo_map assets/textures/country_house/SomeTexture.png
normal_map assets/textures/country_house/SomeTexture_N.png
ao_map assets/textures/country_house/SomeTexture_AO.png
roughness_map assets/textures/country_house/SomeTexture_R.png
```
Texture paths are resolved via `resolveProjectPath()` (relative to project root). ContentRegistry auto-discovers all `.material` files in `assets/materials/` recursively.

When a material has `albedo_map` etc., MaterialTextureLibrary loads textures via:
- `createRGBA8FromFile()` for albedo and normal maps
- `createR8FromFile()` for roughness and AO maps (single-channel)

**Scene file format** (`assets/scenes/*.scene`):
```
environment_profile default
mesh <mesh_id> <px> <py> <pz> <sx> <sy> <sz> <rx> <ry> <rz> material <material_id> tint <r> <g> <b> node <node_id>
light <px> <py> <pz> <r> <g> <b> <radius> <intensity> node <node_id>
collider_box <px> <py> <pz> <hx> <hy> <hz> node <node_id>
player_spawn <px> <py> <pz> <fall_y> node <node_id>
```

**Art direction**: Warm soft lighting, muted color palette, Stanley Parable aesthetic. Light colors around (1.0, 0.97, 0.9) warm white. Tints should be warm muted tones.

The scene file should be structured as follows (adjust coordinates based on actual mesh dimensions):

```
environment_profile default

# Main house structure — place at origin, adjust scale if needed
# The FBX model likely uses centimeters (Unity convention) so may need scale 0.01
mesh country_house 0.0 0.0 0.0 <sx> <sy> <sz> 0.0 0.0 0.0 material ch_wood_exterior tint 1.0 1.0 1.0 node node_house

# Doors — position at door openings (inspect house model for door frame locations)
mesh country_house_door <dx> <dy> <dz> <sx> <sy> <sz> 0.0 0.0 0.0 material ch_door tint 1.0 1.0 1.0 node node_door1

# Interior warm lighting — ceiling-mounted, warm white (Stanley Parable style)
# Place 4-6 interior lights with warm color (1.0, 0.97, 0.9), radius 8-12, intensity 3-5
light <x> <y> <z> 1.0 0.97 0.9 10.0 4.0 node node_light_interior_1
# ... additional interior lights distributed across rooms

# Exterior fill lights — softer, slightly cooler
light <x> <y> <z> 1.0 0.98 0.92 15.0 2.5 node node_light_exterior_1
light <x> <y> <z> 1.0 0.98 0.92 15.0 2.5 node node_light_exterior_2

# Floor collider — large flat box covering the house footprint
collider_box <cx> <cy> <cz> <hx> 0.05 <hz> node node_col_floor

# Wall colliders — approximate the house perimeter with box colliders
# (Add colliders for major walls to prevent player walking through them)

# Player spawn — inside the house, at eye height (~1.6m), looking toward main room
player_spawn <x> 1.6 <z> -5.0 node node_spawn
```

Key considerations:
- FBX models from Unity typically use cm scale or may have scale baked in. The Assimp loader normalizes but check the actual loaded size. If the house appears huge, set scene scale to 0.01 on all axes. If it appears tiny, scale up.
- The material used for the house mesh (ch_wood_exterior) applies as a single material to the entire merged mesh. The FBX has UV-mapped textures, so the albedo map will be sampled correctly.
- Since all submeshes are merged into one by MeshLibrary, the house will render with ONE material. Pick the most representative one (ch_wood_exterior for the exterior view, or ch_indoor_wall if the player is mostly inside). You can place the same house mesh multiple times with different materials if submesh separation is needed, but start simple.
- Alternatively, if the house renders well with just the wood exterior albedo, keep it as one mesh instance. The UV-mapped texture should cover all surfaces since the FBX was designed for this.
- Place warm interior lights at ceiling height inside the house (use the bounding box Y extent to determine ceiling height). Color: warm white (1.0, 0.97, 0.9). Radius 8-12m, intensity 3-5.
- Place 2 softer exterior fill lights to illuminate the outside of the house.
- Add box colliders for: floor (large flat box), exterior walls (approximate with 4 perimeter boxes).
- Player spawn at ~1.6m above the floor, inside the main room.
