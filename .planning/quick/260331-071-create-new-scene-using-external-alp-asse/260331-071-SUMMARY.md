# Quick 260331-071: Create New Scene Using External ALP Assets Summary

Country house environment scene using external FBX mesh assets (ALP_Assets Unity pack) with UV-mapped PBR texture materials — first scene demonstrating the file-based material pipeline (albedo_map, normal_map, ao_map, roughness_map) with externally sourced assets.

## What Was Done

### Task 1: Copy assets, create materials, register meshes (commit: 4ffa541)

- Copied 3 FBX files from Unity ALP_Assets pack: `House.fbx`, `Door01.fbx`, `Doors.fbx`
- Copied 27 texture files (23 PNG + 2 TGA) from the asset pack into `assets/textures/country_house/`
- Created 10 texture-mapped material definition files (`ch_*.material`) with `uv_mode mesh` and PBR parameters tuned to warm Stanley Parable aesthetic
- Added 3 `registerFileAlias` calls in `GameAssets.cpp` for the country house meshes
- Build passes without errors

### Task 2: Create country house scene (commit: d332018)

- Inspected FBX bounds using `assimp info`: house spans X[-740..+740], Y[-1..+789], Z[-506..+685] in cm
- Applied scale 0.01 in scene to convert cm → meters: house is ~14.8m wide, ~7.9m tall, ~11.9m deep
- Placed house at origin with `ch_wood_exterior` material
- Positioned door meshes at front entry (Z=-4.5)
- Added 9 warm lights: 6 interior at Y=6.5 (near ceiling), 3 exterior fill lights
- Added 5 box colliders: floor + 4 perimeter walls
- Player spawn at (0, 1.6, 2.0) inside main room, fall_y=-5.0
