## What Was Done

**Task 1 — Remove ImGui CMake source patch:**

The root CMakeLists.txt contained a 4-line block that used `file(READ/WRITE)` to patch `imgui.cpp` at configure time, reducing scroll speed from 5 lines/notch to 1. This was made redundant by commit 58d5760 which added GLFW-level `AddMouseWheelEvent` scaling in ImGuiLayer.cpp. The CMake patch was removed; scroll behavior is unchanged.

`src/engine/core/MathUtils.h` was created with two inline free functions:
- `safeNormalize(value, fallback)` — uses 0.0001f dot-product threshold
- `makeTransformMatrix(position, rotationDegrees, scale)` — translate → rotate X/Y/Z → scale

**Task 2 — Deduplicate safeNormalize and makeTransformMatrix:**

10 .cpp files had local copies of `safeNormalize` (some in anonymous namespaces, one as a lambda in LevelDef's `resolveLevelHierarchy`). Two files (EditorSceneDocument, LevelDef) additionally had identical `makeTransformMatrix` implementations. All local definitions removed; each file now includes `engine/core/MathUtils.h`.

**Task 3 — Deduplicate parser helpers:**

4 files (ContentRegistry, LevelDef, MaterialDefinition, EnvironmentDefinition) each had identical copies of `throwParseError`, `isCommentOrEmpty`, and `tokenizeRecord`. These are now in `src/game/content/ParseUtils.h`. LevelDef only uses `throwParseError` and `isCommentOrEmpty` (no `tokenizeRecord`) — only those two were removed from that file.
