```cpp
glm::mat4 makeDoorLeafModel(const DoorLeafComponent& leaf, float progress) {
    const float yaw = getDoorLeafYaw(leaf, progress);
    glm::mat4 model = glm::translate(glm::mat4(1.0f), leaf.hingePosition);
    model = glm::rotate(model, glm::radians(yaw), glm::vec3(0.0f, 1.0f, 0.0f));
    model = glm::translate(model, leaf.centerOffsetFromHinge);
    model = glm::scale(model, leaf.closedScale);
    return model;
}
```

```cpp
struct SingleDoorSpawnSpec {
    std::string doorMeshName = "SM_DoorA";
    std::string frameMeshName = "SM_FrameA";
    std::string doorMaterialId = "qdp_door_a";
    std::string frameMaterialId = "stone_default";
    glm::vec3 rootPosition{0.0f};     // world position of door frame center (floor level)

    glm::vec3 frameTint{1.0f};
};
```

Implement `spawnSingleDoor` in `GameplayPrefabs.cpp`. The function needs to:

1. Place the door frame mesh (static, just visual) at rootPosition with scale 0.21, rotated by doorYawDegrees. The frame mesh from the pack is already an arch/frame shape. Place using:
   ```cpp
   builder.addMesh(spec.frameMeshName, spec.rootPosition,
       glm::vec3(0.21f), glm::vec3(0.0f, spec.doorYawDegrees, 0.0f),
       spec.frameTint, spec.frameMaterialId);
   ```

2. Create the door leaf entity. The QDP door mesh origin is at the bottom-center. In Unity, the door is offset about -0.46 in local X from the frame center, meaning the hinge is near the left jamb. At 0.21 scale, the door leaf center offset from hinge is approximately (0.42, 0, 0) in local space (half the scaled width ~0.85/2 = 0.425).

   Compute the hinge world position by rotating the local hinge offset by doorYawDegrees:
   - Local hinge offset from rootPosition: (-0.45, 0, 0) (left jamb) — but this depends on which way the door should open. Use (-0.45, 0, 0.04) rotated by doorYawDegrees.
   - The hinge position in world space = rootPosition + rotate(localHingeOffset, doorYawDegrees)
   - centerOffsetFromHinge = rotate((0.42, 0, 0), 0) — in hinge-local space, the center of the door leaf is offset along the door's width axis
   - closedYaw = doorYawDegrees
   - openYaw = doorYawDegrees - openAngle (opens inward, swinging the free edge away)

   Create the door leaf mesh entity:
   ```cpp
   auto leafMesh = builder.mesh(spec.doorMeshName);
   auto leaf = builder.addMesh(leafMesh, hingeWorldPos, glm::vec3(0.21f),
       glm::vec3(0.0f, spec.doorYawDegrees, 0.0f),
       spec.doorTint, spec.doorMaterialId);
   ```

   Then emplace DoorLeafComponent and StaticColliderComponent on the leaf entity:
   - DoorLeafComponent: hingePosition = hingeWorldPos, centerOffsetFromHinge = (0.42, 0, 0) in door-local coords, closedScale = (0.21, 0.21, 0.21), colliderHalfExtents = (0.42, 0.96, 0.05), closedYaw = doorYawDegrees, openYaw = doorYawDegrees - openAngle
   - StaticColliderComponent: shape=Box, position at leaf center world pos, rotation=(0, doorYawDegrees, 0), halfExtents=(0.42, 0.96, 0.05)

3. Create root entity with DoorComponent and InteractableComponent:
   - DoorComponent: leftLeaf = leaf entity, rightLeaf = entt::null, interactDistance, openDuration, etc.
   - If spec.locked: InteractableComponent with promptText = spec.lockedPrompt, busyText = "", enabled = true, but do NOT emplace DoorComponent (so the door system won't try to open it). Instead just emplace InteractableComponent alone on the root.
   - If not locked: InteractableComponent with promptText = "E  OPEN DOOR", busyText = "OPENING DOOR"

   The root entity TransformComponent position should be at the center of the door opening (rootPosition + some vertical offset for the interaction raycast point). Place it at rootPosition + (0, 1.0, 0) so the interaction test hits roughly handle height.
