**Part B: Wire locked door interaction stubs in GenericFileScene**

The `.scene` file format does NOT support attaching `InteractableComponent` to mesh entities (Pitfall 6). The interaction stubs for the metal door and chained door must be created via `buildScriptedGeometry`.

Modify `GenericFileScene.cpp` to conditionally set `request_.buildScriptedGeometry` for the institutional_room scene. The approach:

1. Add `#include "game/components/InteractableComponent.h"` to GenericFileScene.cpp
2. In `onEnter()`, after setting `request_.registerAssets`, check if `request_.levelId == "institutional_room"` and if so, set `request_.buildScriptedGeometry` to a lambda that:
   a. Spawns the metal door mesh entity via `builder.addMesh("office_door", ...)` at X=0.0, Y=0.0, Z=5.95 with `metal_default` material and gray tint
   b. Attaches `InteractableComponent` with `promptText = "E  This door is locked"` and `enabled = true`
   c. Spawns the chained door mesh entity via `builder.addMesh("office_door", ...)` at X=+2.5, Y=0.0, Z=5.95 with `stone_default` material and off-white tint
   d. Attaches `InteractableComponent` with `promptText = "E  This door is locked"` and `enabled = true`

The cleanest path: Place ONLY the wooden door in the .scene file. Metal and chained doors come from `buildScriptedGeometry` with their InteractableComponent attached. Do NOT put metal/chained door mesh records in the .scene file (would create duplicates).

```cpp
// In GenericFileScene::onEnter(), replace request_.buildScriptedGeometry = {};
if (request_.levelId == "institutional_room") {
    request_.buildScriptedGeometry = [](LevelBuilder& builder) {
        // Metal door (center) - locked stub per D-04
        auto metalDoor = builder.addMesh("office_door",
            glm::vec3(0.0f, 0.0f, 5.95f),        // position
            glm::vec3(1.0f, 1.0f, 1.0f),          // scale
            glm::vec3(0.0f, 180.0f, 0.0f),        // rotation (facing south)
            glm::vec3(0.60f, 0.58f, 0.55f),       // tint (gray metal)
            std::string("metal_default"));          // material
        builder.registry().emplace<InteractableComponent>(metalDoor,
            InteractableComponent{
                .promptText = "E  This door is locked",
                .interactDistance = 2.0f,
                .enabled = true
            });

        // Chained door (right) - locked stub per D-04
        auto chainedDoor = builder.addMesh("office_door",
            glm::vec3(2.5f, 0.0f, 5.95f),         // position
            glm::vec3(1.0f, 1.0f, 1.0f),           // scale
            glm::vec3(0.0f, 180.0f, 0.0f),         // rotation (facing south)
            glm::vec3(0.88f, 0.86f, 0.82f),        // tint (off-white)
            std::string("stone_default"));           // material
        builder.registry().emplace<InteractableComponent>(chainedDoor,
            InteractableComponent{
                .promptText = "E  This door is locked",
                .interactDistance = 2.0f,
                .enabled = true
            });
    };
} else {
    request_.buildScriptedGeometry = {};
}
```

Add `#include <optional>` and `#include <string>` if not already present. The `addMesh` overload taking `std::optional<glm::vec3> tint` and `std::optional<std::string> materialId` requires wrapping the string literal in `std::string(...)`.

Also add to GenericFileScene.h: `#include "game/level/LevelBuilder.h"` if needed (it may already be transitively included). Verify the include chain.
