<objective>
Consolidate three editor object kinds (BoxCollider, CylinderCollider, Trigger) into a single Collider kind backed by LevelColliderPlacement. Update all editor subsystems: document model, inspector, outliner, preview renderer, viewport interaction, command system, asset browser, preview world, and selection system.

Purpose: Simplifies editor data model from 3 collider-related kinds to 1, enabling shape/mode dropdown selection per D-12. Makes the editor directly reflect the unified ColliderComponent from the game layer.
Output: Single Collider kind in editor with full inspector/outliner/renderer support, all editor code compiles.
</objective>
