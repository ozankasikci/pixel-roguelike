Create a small editor-only preferences helper and wire it into the level editor instead of storing theme state in layout presets or `assets/project.cfg`, per D-12 and the research recommendation. This task should leave `Warm Studio Dark` as the coded default before the later checkpoint decides whether that default needs to change.

1. Add `src/editor/core/EditorUiPreferences.h` with this exact contract:
   ```cpp
   struct EditorUiPreferences {
       ImGuiFontPreset fontPreset = ImGuiFontPreset::SystemSans;
       ImGuiThemePreset themePreset = ImGuiThemePreset::WarmStudioDark;
   };

   EditorUiPreferences loadEditorUiPreferences(const std::string& path);
   void saveEditorUiPreferences(const EditorUiPreferences& prefs, const std::string& path);
   ```

2. In `src/editor/core/EditorUiPreferences.cpp`, implement simple key=value parsing and writing with this exact on-disk format:
   ```text
   font_preset=SystemSans
   theme_preset=WarmStudioDark
   ```
   Behavior requirements:
   - missing file returns the defaults above
   - unknown keys are ignored
   - unknown enum strings fall back to the defaults above
   - write both keys on every save in the order `font_preset`, then `theme_preset`
   - do not depend on ImGui runtime state; this helper should be plain file I/O + enum conversion

3. Register the new source file in `src/editor/CMakeLists.txt`.

4. Add `editor_ui.ini` to `.gitignore` as editor-local state alongside `imgui.ini`, `editor_window.ini`, and `editor_build.ini`.

5. Add `tests/editor/test_editor_ui_preferences.cpp` and register it in `tests/editor/CMakeLists.txt` as `test_editor_ui_preferences`. The test must cover:
   - missing file -> `SystemSans` + `WarmStudioDark`
   - save -> load roundtrip preserves `RobotoUnreal` + `SpectrumInspiredDark`
   - unknown tokens (for example `font_preset=Nope` and `theme_preset=Nope`) fall back to the defaults

6. In `apps/level_editor/main.cpp`, wire the helper into the level editor only. Do not modify `apps/runtime/main.cpp`, `RenderSystem`, or any runtime overlay path in this phase.

7. In `apps/level_editor/main.cpp`, add:
   ```cpp
   #include "editor/core/EditorUiPreferences.h"
   constexpr const char* kEditorUiConfigFile = "editor_ui.ini";
   ```

8. Immediately after `imgui.init(window.handle());` and before the first `renderStartupProgress(...)` call, load the preferences and request both presets:
   ```cpp
   const EditorUiPreferences uiPrefs = loadEditorUiPreferences(kEditorUiConfigFile);
   imgui.requestThemePreset(uiPrefs.themePreset);
   imgui.requestFontPreset(uiPrefs.fontPreset);
   ```
   Then initialize the menu-state variables from the loaded prefs instead of from `imgui.fontPreset()` alone:
   ```cpp
   ImGuiThemePreset editorThemePreset = uiPrefs.themePreset;
   ImGuiFontPreset editorFontPreset = uiPrefs.fontPreset;
   ```

9. When the user changes the theme from `View -> Interface Theme`, save immediately:
   ```cpp
   saveEditorUiPreferences(EditorUiPreferences{
       .fontPreset = editorFontPreset,
       .themePreset = editorThemePreset,
   }, kEditorUiConfigFile);
   ```

10. When the user changes the font from `View -> Interface Font`, save immediately using the same helper and file. This phase should close the existing font-persistence gap at the same time as theme persistence.

11. At shutdown, after `saveWindowGeometry(window.handle());` and before `saveBuildConfig(...)`, write one last `saveEditorUiPreferences(...)` call so the final selection also persists if the user changed theme/font late in the session.

12. Keep the fallback/default editor theme as `WarmStudioDark` per D-05 for now. If `editor_ui.ini` is absent or invalid, the editor should start with `WarmStudioDark` without modifying project-scoped config files. A later post-checkpoint task will change this coded default only if the approved winner is `SpectrumInspiredDark` or `SoftLightTooling`.
