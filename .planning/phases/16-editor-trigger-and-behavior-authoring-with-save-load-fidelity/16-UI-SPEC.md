# Phase 16 — UI Design Contract

> Visual and interaction contract for the level editor's trigger and behavior authoring UI.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|
| Tool | none — Dear ImGui, C++ native |
| Preset | not applicable (no web framework) |
| Component library | Dear ImGui v1.92.6 via existing `ImGuiLayer` infrastructure |
| Icon library | none — text labels only (no icon font loaded) |
| Font | JetBrains Mono (default: `GraphiteDense` theme) or user-selected font preset |

**shadcn gate result:** Not applicable. This project is a C++ game engine editor using Dear ImGui. No React/Next.js/Vite stack. shadcn is not relevant.

**Existing theme default:** `GraphiteDense` — dark neutral palette, compact spacing (3px rounding, 5px/3px frame padding, 5px/3px item spacing). Source: `src/engine/ui/ImGuiLayer.cpp:311`.

## Spacing Scale

Dear ImGui spacing is governed by the active `ThemePresetDefinition`. The `GraphiteDense` default values are:

| Token | ImGui value | Usage |
|-------|-------------|-------|
| xs | 3px (framePadding.y) | Tight label rows in behavior action list |
| sm | 5px (framePadding.x / itemSpacing.x) | Frame and cell padding |
| md | 8px (indentSpacing derived) | Collapsed section indent |
| lg | 14px (indentSpacing) | Section block indent |
| xl | 20px (windowPadding.x) | Inspector panel outer margin |

Source: `ImGuiLayer.cpp` `kGraphiteDense` definition — pre-populated, no user input required.

**Exceptions:**
- Action list rows use `ImGui::Spacing()` (1 implicit line gap) between each `ActionEntry` to maintain visual grouping without increasing padding globally.
- Trigger resize handles (gizmo corners) use a minimum 8px hit-test zone for usability, matching the collider gizmo convention.

## Typography

Dear ImGui renders a single loaded font at runtime size. There is no multi-size typography stack in ImGui; relative emphasis is achieved via `ImGui::TextDisabled()`, `ImGui::TextColored()`, and separator lines.

| Role | ImGui construct | Effective size | Weight |
|------|----------------|---------------|--------|
| Body / label | `ImGui::TextUnformatted()` | 14px (GraphiteDense font size) | regular (400) |
| Dimmed / hint | `ImGui::TextDisabled()` | 14px at ~60% alpha | regular (400) |
| Section header | `ImGui::CollapsingHeader()` | 14px, ImGui header bg tint | regular (400) |
| Validation error | `ImGui::TextColored(ImVec4(1.0f, 0.3f, 0.3f, 1.0f), ...)` | 14px, red tint | regular (400) |

Source: `EditorInspectorPanel.cpp:581` for the error color pattern; `ImGuiLayer.cpp:325` for 14px body size in GraphiteDense.

Line height is controlled by Dear ImGui's internal `GetTextLineHeightWithSpacing()` — approximately 1.4x at GraphiteDense density.

## Color

All colors use the active ImGui theme. The design contract specifies semantic usage, not overrides.

### Theme colors (GraphiteDense defaults)

| Role | ImVec4 (RGBA float) | Hex approx | Usage |
|------|---------------------|-----------|-------|
| Dominant (60%) — window bg | `(0.05, 0.06, 0.07, 0.98)` | `#0D0F12` | Panel backgrounds, all editor windows |
| Secondary (30%) — frame / child bg | `(0.07, 0.08, 0.09, 0.98)` | `#12151A` | Inspector section frames, dropdown backgrounds |
| Accent (10%) — button hover | `(0.34, 0.36, 0.39, 1.0)` | `#575C64` | Interactive element hover state only |
| Destructive | `ImVec4(1.0f, 0.3f, 0.3f, 1.0f)` | `#FF4D4D` | Validation errors, remove-action button text only |

Source: `ImGuiLayer.cpp:328–345` for GraphiteDense color values; `EditorInspectorPanel.cpp:581` for destructive/error color.

**Accent reserved for:**
- "+ Add Action" button hover state
- Action type combo dropdown hover
- Target node ID combo hover
- "Add Trigger Zone" context menu item highlight

**Accent NOT used for:**
- Trigger wireframe colors (those are viewport render tints, not ImGui theme colors)
- Behavior section headers
- Normal text labels

### Viewport wireframe colors (pre-existing, source: `EditorScenePreviewRenderer.cpp:210–229`)

| Object | Tint (glm::vec3 RGB) | Hex approx | Usage |
|--------|---------------------|-----------|-------|
| Box trigger | `(0.20, 0.80, 0.20)` | `#33CC33` | Box trigger volume wireframe |
| Sphere trigger | `(0.20, 0.40, 0.80)` | `#3366CC` | Sphere trigger volume wireframe |
| Interaction distance ring | `(0.80, 0.60, 0.20)` | `#CC9933` | Interactable distance visualization ring |

Trigger wireframes: 1.5px line width, ignoreDepth = true (overlay through geometry), unlit rendering. Source: `EditorScenePreviewRenderer.cpp:215–216`.

Interaction distance ring follows the same wireframe parameters — 1.5px, ignoreDepth = true, unlit — rendered as a scaled sphere/torus approximation using the cube mesh at `interactionDistance` radius. (New in phase 16, per D-10.)

## Component Inventory

All components are Dear ImGui native widgets. No custom widget library.

### Trigger inspector section

```
[=] Trigger Zone                    (CollapsingHeader, DefaultOpen)
  Shape:        [Box v]             (Combo: "Box", "Sphere")
  Position:     [X: 0.0] [Y: 0.0] [Z: 0.0]   (DragFloat3, step 0.1)
  Half Extents: [X: 1.0] [Y: 1.0] [Z: 1.0]   (DragFloat3, step 0.05, min 0.05) — Box only
  Radius:       [1.0]               (DragFloat, step 0.05, min 0.05) — Sphere only
  Node ID:      [trigger_001     ]  (InputText, 64-char limit)
```

Shape combo switches between half-extents row (Box) and radius row (Sphere). Uses `renderInspectorPropertyRow()` from `EditorPanelUtils.cpp` — two-column label/value layout.

### Behavior editing sections (on mesh, light, and trigger entities)

```
[=] On Activate                     (CollapsingHeader)
  [Door] door_01: Toggle            (one row per ActionEntry)
  [+ Add Action]                    (Button, full width)

[=] On Enter                        (CollapsingHeader)
  (empty)
  [+ Add Action]

[=] On Exit                         (CollapsingHeader)
  (empty)
  [+ Add Action]

[=] On Timer                        (CollapsingHeader)
  (empty)
  [+ Add Action]
```

Sections only rendered when the entity has a `BehaviorComponent` or when "+ Add Action" is first pressed (auto-creates the component).

### Action entry row

```
[X]  [Category v]  [ActionType v]  [TargetNodeID v]  [param fields...]
```

- `[X]` — SmallButton to remove this action entry
- Category + ActionType: two Combo widgets, category filters the action type list
- TargetNodeID: Combo with type-to-filter; lists all entities with a `nodeId`; "self" always first
- Param fields: depend on action type (see Parameter widgets table below)

### Action type categorized dropdown

Category combo (left) filters action type combo (right):

| Category | Action types (D-08 core subset) |
|----------|--------------------------------|
| Door | Open, Close, Toggle |
| Lighting | SetLight |
| Audio | PlaySound |
| Entity | EnableEntity, DisableEntity |
| Timing | Delay |

Deferred types (FlickerLight, ShowMessage, EmitEvent, LockPlayer, UnlockPlayer, TeleportPlayer) are NOT shown in this phase.

### Parameter widgets per action type

| Action type | Parameter fields | Widget |
|------------|-----------------|--------|
| Open | (none beyond target) | — |
| Close | (none beyond target) | — |
| Toggle | (none beyond target) | — |
| SetLight | `enabled`: bool | Checkbox |
| PlaySound | `soundId`: string | InputText (64 chars) |
| EnableEntity | (none beyond target) | — |
| DisableEntity | (none beyond target) | — |
| Delay | `duration`: float (seconds) | DragFloat, step 0.05, min 0.0, max 60.0, "%.2f s" |

### Interactable editing section

```
[ ] Make Interactable               (Checkbox, inline label)

--- shown only when checked: ---
  Prompt:       [Press E to open ]  (InputText, 64 chars)
  Distance:     [2.0             ]  (DragFloat, step 0.1, min 0.1, max 10.0, "%.1f m")
  Dot Threshold:[0.7             ]  (DragFloat, step 0.05, min 0.0, max 1.0, "%.2f")
```

"Make Interactable" checkbox is rendered in the mesh entity inspector section using the existing `renderInspectorPropertyRow()` layout. When unchecked all three fields are hidden (no indent, no blank space).

### Outliner entry for Trigger kind

```
Trigger #N [box] [trigger_001]     (text label, same TreeNode style as Mesh/Light)
```

Format follows `editorSceneObjectLabel()` convention: kind name + `#id` + `[shape]` + `[nodeId]` if set.

### Context menu (right-click on entity in outliner)

```
Add Trigger Zone                   (new menu item, all entity kinds)
```

Opens a minimal modal or inline-spawns a new Trigger object parented to the clicked entity at `position = entity.position`.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Add Action" |
| Trigger zone context menu item | "Add Trigger Zone" |
| Interactable toggle label | "Make Interactable" |
| Empty behavior section (no actions) | "(none)" — `ImGui::TextDisabled("(none)")` |
| Empty target node combo hint | "self" (always first, always selected by default) |
| Validation error — missing target | "Target node not found in scene" |
| Validation error — missing sound ID | "Sound ID required for PlaySound" |
| Remove action button tooltip | "Remove action" (SmallButton labeled "X", `ImGui::SetItemTooltip("Remove action")`) |

Source for destructive pattern: CONTEXT.md has no override; Phase 10 established the delete-without-modal convention for editor objects.

## Interaction Contracts

### Trigger volume gizmo (D-02)

- Selecting a Trigger in the outliner activates its drag handles in the viewport.
- Box trigger: 6 face handles (one per axis-aligned face) — drag to resize `halfExtents` on that axis. Handle renders as a small colored square (8x8px screenspace) at face center.
- Sphere trigger: 6 radius handles at cardinal directions — drag uniformly updates `radius`.
- Gizmo handle color: matches trigger wireframe tint (`#33CC33` for Box, `#3366CC` for Sphere) at 80% alpha when idle, 100% alpha on hover.
- All gizmo mutations go through the existing `EditorCommand` undo stack.
- While a handle is being dragged, the inspector fields update live (same frame).

### Behavior section expand/collapse state

- All four event sections (`onActivate`, `onEnter`, `onExit`, `onTimer`) start collapsed by default.
- `onActivate` starts open if the entity already has actions in that list.
- State is per-selected-entity (not persisted across sessions).

### Target node ID combo

- Combo lists all entities in the document that have a non-empty `nodeId` field.
- "self" is always index 0 and is the initial selection when a new action is added.
- Filtering is case-insensitive substring match on `nodeId`.
- If the current `targetNodeId` value is not found in the scene, show `ImGui::TextColored` error below the combo: "Target node not found in scene".

### Interactable distance ring

- Rendered every frame when an entity has `isInteractable = true`, regardless of selection state.
- Ring color: `glm::vec3(0.80f, 0.60f, 0.20f)` (`#CC9933` warm amber), 1.5px width, ignoreDepth = true, unlit.
- Rendered as a scaled sphere approximation (cube mesh at `interactionDistance` diameter) — same technique as trigger wireframes.

### Save/load round-trip

- After any behavior or trigger edit, the scene is marked dirty (title bar shows unsaved indicator).
- On save, `toLevelDef()` serializes triggers into `LevelDef::triggers` and behavior/interactable data into the mesh/light payload structs.
- On load, `loadFromSceneFile()` promotes `readOnlyTriggers_` to full `EditorSceneObject::Trigger` entries with behavior data intact.
- Round-trip fidelity is verified by the new test in `tests/game/test_behavior_trigger_roundtrip.cpp` (per D-13).
