**In LevelDef.cpp anonymous namespace**, extract these helpers:

1. `parseNodeMetadata()` — handles `node X` and `parent X` token pairs:
```cpp
// Returns true if the token was consumed (node or parent), false otherwise.
// Caller should continue to next token on true, or try other metadata on false.
bool parseNodeMetadata(const std::string& path, int lineNumber,
                       const std::vector<std::string>& tokens, std::size_t& index,
                       std::string& outNodeId, std::string& outParentNodeId) {
    if (tokens[index] == "node") {
        if (index + 1 >= tokens.size())
            throwParseError(path, lineNumber, "missing node id after 'node'");
        outNodeId = tokens[index + 1];
        index += 2;
        return true;
    }
    if (tokens[index] == "parent") {
        if (index + 1 >= tokens.size())
            throwParseError(path, lineNumber, "missing parent node id after 'parent'");
        outParentNodeId = tokens[index + 1];
        index += 2;
        return true;
    }
    return false;
}
```

2. `parseShapeTokens()` — handles `fire_once` token for colliders:
```cpp
bool parseFireOnceToken(const std::vector<std::string>& tokens, std::size_t& index,
                        bool& outFireOnce) {
    if (tokens[index] == "fire_once") {
        outFireOnce = true;
        index += 1;
        return true;
    }
    return false;
}
```
