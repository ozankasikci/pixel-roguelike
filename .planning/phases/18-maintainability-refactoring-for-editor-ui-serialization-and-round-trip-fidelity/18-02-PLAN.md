**Step 1: Replace the three light parser blocks with one unified block.**

Delete the three separate parser blocks:
- `if (kind == "light") { ... }` (~line 618, handles point lights)
- `if (kind == "spot_light") { ... }` (~line 651, handles spot lights)
- `if (kind == "dir_light") { ... }` (~line 692, handles directional lights)

Replace with a single unified `if (kind == "light") { ... }` block that:

1. Reads a type token (`point`, `spot`, `directional`) from the stream
2. Maps the type token to `LightType` enum values
3. Based on the type, reads the appropriate positional arguments:
   - `point`: `<x> <y> <z> <r> <g> <b> <radius> <intensity>`
   - `spot`: `<x> <y> <z> <dx> <dy> <dz> <r> <g> <b> <radius> <intensity> <inner> <outer> <shadows>`
   - `directional`: `<dx> <dy> <dz> <r> <g> <b> <intensity>`
4. Reads remaining tokens for metadata using `parseNodeMetadata()` (from Plan 01)
5. Sets `currentKind = CurrentEntityKind::Light` and `currentIndex = data.lights.size()` **before** pushing — this is CRITICAL for behavior sub-line routing (see RESEARCH.md Pitfall 5)
6. Pushes the placement to `data.lights`

Unified parser structure:
```cpp
if (kind == "light") {
    LevelLightPlacement placement;
    std::string typeToken;
    if (!(stream >> typeToken)) {
        throwParseError(path, lineNumber, "invalid light record: missing type (point/spot/directional)");
    }

    if (typeToken == "point") {
        placement.type = LightType::Point;
        if (!(stream >> placement.position.x >> placement.position.y >> placement.position.z
                     >> placement.color.r >> placement.color.g >> placement.color.b
                     >> placement.radius >> placement.intensity)) {
            throwParseError(path, lineNumber, "invalid light point record");
        }
    } else if (typeToken == "spot") {
        placement.type = LightType::Spot;
        if (!(stream >> placement.position.x >> placement.position.y >> placement.position.z
                     >> placement.direction.x >> placement.direction.y >> placement.direction.z
                     >> placement.color.r >> placement.color.g >> placement.color.b
                     >> placement.radius >> placement.intensity
                     >> placement.innerConeDegrees >> placement.outerConeDegrees)) {
            throwParseError(path, lineNumber, "invalid light spot record");
        }
        // Read shadows bool
        std::string shadowToken;
        if (stream >> shadowToken) {
            bool hasShadows = false;
            if (tryParseBoolToken(shadowToken, hasShadows)) {
                placement.castsShadows = hasShadows;
            } else {
                // Not a bool — put it back as remaining token for metadata parsing
                // Handle via collectRemainingTokens approach
            }
        }
        // NOTE: The shadow token handling needs care. In the old format, the shadow bool
        // was a positional argument. Keep the same pattern: read it positionally.
        // Simplest: read shadow bool directly from stream before collectRemainingTokens.
    } else if (typeToken == "directional") {
        placement.type = LightType::Directional;
        if (!(stream >> placement.direction.x >> placement.direction.y >> placement.direction.z
                     >> placement.color.r >> placement.color.g >> placement.color.b
                     >> placement.intensity)) {
            throwParseError(path, lineNumber, "invalid light directional record");
        }
    } else {
        throwParseError(path, lineNumber, "unknown light type: '" + typeToken + "' (expected point/spot/directional)");
    }

    // Parse remaining metadata tokens (node, parent)
    const auto tokens = collectRemainingTokens(stream);
    for (std::size_t index = 0; index < tokens.size();) {
        if (parseNodeMetadata(path, lineNumber, tokens, index,
                             placement.nodeId, placement.parentNodeId)) {
            continue;
        }
        throwParseError(path, lineNumber, "invalid light metadata token: '" + tokens[index] + "'");
    }

    currentKind = CurrentEntityKind::Light;
    currentIndex = data.lights.size();
    data.lights.push_back(std::move(placement));
    continue;
}
```

For the spot light shadow token: read it the same way the old parser did — as a positional bool token extracted from the stream BEFORE calling collectRemainingTokens. Check the old `spot_light` parser to see the exact extraction order. The old format reads shadows as the 14th positional token.
