1. In `CascadedShadowMap.cpp`, snap each cascade's orthographic projection center to shadow-map texel increments before building the final light-space matrix. Use the current cascade resolution to derive the texel size, so small camera motion no longer causes continuous sub-texel shimmer.

2. In `apps/level_editor/main.cpp`, add:
   ```cpp
   enum class EditorPreviewQuality { Fast, Balanced, High };
   ```
   with these exact defaults:
   - `Fast`: render scale `0.67`, SSAO disabled, `shadowResolutionIndex = 0`
   - `Balanced`: render scale `0.75`, SSAO enabled + half-res, `shadowResolutionIndex = 1`
   - `High`: render scale `1.0`, SSAO enabled + full-res, `shadowResolutionIndex = 2`

3. Feed the quality preset into the render path by passing separate internal and output sizes:
   - `internalWidth = round(outputWidth * previewRenderScale)`
   - `internalHeight = round(outputHeight * previewRenderScale)`
   - `outputWidth/outputHeight` stay at the real viewport size

4. Add a visible `Preview Quality` control in the editor UI and keep the existing pass timing overlay visible in play preview.

5. Document the new preview-quality workflow in `docs/editor.md`, including the default preset meanings and the fact that fullscreen preview now intentionally uses render scale for responsiveness.

6. Add `tests/editor/test_runtime_preview_quality.cpp` to cover:
   - preset mapping values
   - render-scale clamping
   - internal-size calculation from output size
