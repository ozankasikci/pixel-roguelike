<objective>
Add a minimal local reflection-probe system for indoor scenes so the renderer can produce convincing room-shaped reflections instead of relying on global sky reflections alone.

Purpose: global IBL improves everything, but interior rooms like `initial_scene` still need local context. This plan adds the smallest practical authoring/runtime system that fixes that class of scene.

Output: scene-format reflection probes, editor inspection/serialization, runtime update-once cubemap capture, and box-projected local probe shading in `scene.frag`.
</objective>
