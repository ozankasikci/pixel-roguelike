Purpose: close the largest current visual gap first. Doors, metal, stone, and other glossy surfaces should respond to a real captured environment instead of looking reflective only because of direct-light highlights and bloom.

Output: reflection-ready sky/environment map cache, prefiltered cubemap generation, BRDF LUT generation, and `scene.frag` integration for specular IBL.

  <action>
Wire the new environment-reflection resources into the shared scene pass.

1. In `TextureUnits.h`, reserve two named texture units:
   ```cpp
   inline constexpr int kEnvironmentSpecular = 12;
   inline constexpr int kEnvironmentBrdfLut = 13;
   ```

2. In `SceneRenderPipeline.h`, add a `SkyTextureLibrary skyTextures_;` member so the shared pipeline can resolve the reflection-ready cubemap directly from `input.postParams->sky.cubemapFacePaths`.

3. In `SceneRenderPipeline::init()`, call `skyTextures_.initReflectionResources()`.

4. In `SceneRenderPipeline::renderScenePass()`, before `renderer_->drawScene(...)`:
   - resolve the sky reflection set from `input.postParams->sky.cubemapFacePaths`
   - bind the prefiltered cubemap to `TextureUnits::kEnvironmentSpecular`
   - bind the BRDF LUT to `TextureUnits::kEnvironmentBrdfLut`
   - set these uniforms on the scene shader:
     ```cpp
     uEnvironmentSpecularMap
     uEnvironmentBrdfLut
     uEnvironmentSpecularMipCount
     uEnvironmentReflectionsEnabled
     uEnvironmentReflectionStrength
     ```
   - set `uEnvironmentReflectionsEnabled = 1` only if cubemap faces are configured and `input.postParams->sky.cubemapStrength > 0.0f`
   - set `uEnvironmentReflectionStrength` from `input.postParams->sky.cubemapStrength`

5. In `assets/shaders/game/scene.frag`, add the environment-specular uniforms and integrate specular IBL into the existing PBR path:
   - compute reflection vector with `reflect(-V, N)`
   - sample the prefiltered cubemap with `textureLod(...)`
   - use `roughness * float(uEnvironmentSpecularMipCount - 1)` as the mip level
   - sample the BRDF LUT with `vec2(max(dot(N, V), 0.0), roughness)`
   - accumulate:
     ```glsl
     vec3 iblSpecular = prefiltered * (F * envBrdf.x + envBrdf.y);
     totalLight += iblSpecular * uEnvironmentReflectionStrength;
     ```

6. Keep the current direct-lighting loop intact. This task adds environment specular on top; it does not replace direct-light shading or hemisphere ambient.
