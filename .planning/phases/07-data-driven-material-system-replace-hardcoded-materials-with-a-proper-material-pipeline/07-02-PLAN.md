<objective>
Delete the MaterialKind enum and refactor the entire rendering pipeline from type-based branching to property-driven feature flags. This is the core surgical change of Phase 7: the shader stops switching on an integer material type and instead reads individual boolean flags and float properties from uniforms.

Purpose: Per D-07, material behavior is fully defined by properties. One PBR uber-shader with no type branching. This also fixes the engine/game layering violation where Renderer.h included MaterialKind.h from the game layer.
Output: Deleted MaterialKind.h, refactored scene.frag/scene.vert, updated RenderMaterialData, updated all call sites across game and editor.
</objective>
