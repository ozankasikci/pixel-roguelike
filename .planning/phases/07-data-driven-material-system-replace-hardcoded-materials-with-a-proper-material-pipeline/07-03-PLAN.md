4. Add right-click context menu for material nodes with three actions:

**New Material:**
- Show an ImGui popup with a text input for material ID and an optional parent combo (listing all existing material IDs plus "none")
- On confirm: Create a new `.material` file at `assets/materials/<id>.material` with content:
  ```
  id <user_entered_id>
  parent <selected_parent_or_omit_if_none>
  roughness_bias 0.82
  specular_level 0.20
  ```
- Call `saveMaterialDefinitionAsset(path, definition)` to write the file to disk
- Call `content.addMaterial(definition, path)` to register in ContentRegistry in-memory (method added by Plan 04)

**Rename:**
- Show a text input popup pre-filled with the current ID
- On confirm: Read the .material file, update the `id` field, write it back with the new name
- Rename the file on disk from `<old_id>.material` to `<new_id>.material`
- Update ContentRegistry: call `content.removeMaterial(oldId)` then `content.addMaterial(updatedDef, newPath)`

**Delete:**
- Show a confirmation popup ("Delete material <id>? This cannot be undone.")
- On confirm: Delete the .material file from disk using `std::filesystem::remove()`
- Call `content.removeMaterial(id)` to remove from ContentRegistry in-memory (method added by Plan 04)

5. Single-click on a material node should set the editor's selected asset to that material (for the inspector panel to pick up). Follow the same selection pattern used for scenes/meshes.

**EditorInspectorPanel.cpp -- Material Inspector Refactor:**

1. Read the full file to understand the existing material inspector section. Plan 02 already removed the "Shading Model" combo box. This task adds the property-driven replacement.

2. The material inspector section (the function that renders when a material is selected for inspection) should be organized into these property groups:

**Group: "Base Properties"**
- `base_color`: ImGui::ColorEdit3 for RGB (mapped to `def.baseColor`)
- `uv_mode`: ImGui::Combo with "Mesh" / "World Projected" options
- `uv_scale`: ImGui::DragFloat2 for X/Y scale (range 0.01 to 10.0, speed 0.01)

**Group: "PBR Properties"**
- `roughness_bias`: ImGui::SliderFloat range [0.0, 1.0] (this IS the roughness value now)
- `roughness_scale`: ImGui::SliderFloat range [0.0, 2.0] (multiplier on roughness, default 1.0)
- `metalness`: ImGui::SliderFloat range [0.0, 1.0]
- `specular_level`: ImGui::SliderFloat range [0.0, 2.0]
- `normal_strength`: ImGui::SliderFloat range [0.0, 3.0]
- `ao_strength`: ImGui::SliderFloat range [0.0, 2.0]
- `light_tint_response`: ImGui::SliderFloat range [0.0, 1.0]
- `emissive_strength`: ImGui::SliderFloat range [0.0, 10.0]

**Group: "Feature Flags"** (per D-08)
- `animated`: ImGui::Checkbox (wax flame flicker)
- `subsurface`: ImGui::Checkbox (moss SSS)
- `detail_brick`: ImGui::Checkbox
- `detail_wood`: ImGui::Checkbox
- `detail_stone`: ImGui::Checkbox
- `detail_floor`: ImGui::Checkbox

**Group: "Texture Maps"**
- `albedo_map`: text display of path (or "none")
- `normal_map`: text display of path (or "none")
- `roughness_map`: text display of path (or "none")
- `ao_map`: text display of path (or "none")
- `procedural_source`: ImGui::Combo with None/GeneratedBrick/GeneratedStone/GeneratedSmooth/GeneratedFloor/GeneratedCeiling options

**Group: "Inheritance"**
- `parent`: ImGui::Combo listing all material IDs from ContentRegistry plus "none"
- Display which properties are inherited (show in a lighter color or with an "(inherited)" label)

3. For each property slider/checkbox/combo:
   - Track a `dirty` flag. When any value changes, set `dirty = true`.
   - On dirty: call `saveMaterialDefinitionAsset(materialFilePath, draft)` to write the updated definition back to disk.
   - The `draft` is a `MaterialDefinition` copy that the inspector modifies. On save, write it.

4. Add the preview sphere (per D-11):
   - At the top of the material inspector (before the property groups), render a preview sphere using `EditorAssetPreviewRenderer::drawMaterialPreview()`.
   - Resolve the current material to `RenderMaterialData` via `MaterialTextureLibrary::resolve(materialId)`.
   - Pass it to `drawMaterialPreview(material, bgColor, "inspector")` where bgColor matches the editor background.
   - The preview should be approximately 128x128 or 200x200 pixels -- check what size the existing preview renderer produces and match it.

5. For the preview to update live as properties change, after saving the .material file, trigger a re-resolve of the material in MaterialTextureLibrary by calling `texLibrary.reloadMaterial(materialId)`. Plan 04's hot-reload will also pick up external changes, but calling reloadMaterial() directly gives instant feedback for editor-originated changes without waiting for the 500ms poll.

6. Per D-15 (validation on save): Before writing the .material file, validate using `content.validateMaterialDefinition(draft, errorMsg)` (method added by Plan 04):
   - If validation fails, show the error inline (ImGui::TextColored red) and do NOT save.
