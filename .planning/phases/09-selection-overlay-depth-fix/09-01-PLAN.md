Replace the single `objects.push_back(RenderObject{...})` call (lines 241-251) with TWO push_back calls per selected object, in this exact order:

**Pass 1 — Ghost wireframe (pushed first, drawn first):**
```cpp
// Ghost pass: draws through all geometry at 20% brightness
objects.push_back(RenderObject{
    cube,
    makeModelMatrix(center, size),
    tint * 0.20f,                        // 20% of primary/secondary tint
    materials.resolve("metal_default"),
    true,    // wireframe
    true,    // ignoreDepth = true (draws through everything)
    true,    // unlit
    primary ? 2.0f : 1.5f               // thinner line for ghost
});
```

**Pass 2 — Primary wireframe (pushed second, drawn second, overwrites ghost where visible):**
```cpp
// Primary pass: depth-tested, only visible where object is not occluded
objects.push_back(RenderObject{
    cube,
    makeModelMatrix(center, size),
    tint,                                // full brightness tint
    materials.resolve("metal_default"),
    true,    // wireframe
    false,   // ignoreDepth = false (respects depth buffer)
    true,    // unlit
    primary ? 4.0f : 2.5f               // original line widths
});
```

The ghost is drawn first because objects are rendered in list order by `Renderer::drawScene()`. Since the ghost uses `ignoreDepth = true`, it appears everywhere including through walls. The primary uses `ignoreDepth = false`, so it only draws where the depth test passes (object is visible). Where both draw the same pixel, the primary overwrites the ghost because it draws second. Where the object is fully occluded, only the dim ghost lines remain visible.

Do NOT modify:
- The existing tint values (primary: 1.30, 0.92, 0.24; secondary: 0.50, 1.00, 0.62)
- The `RenderObject` struct in Renderer.h
- The `Renderer::drawScene()` method
- Any other function in EditorScenePreviewRenderer.cpp
- The bounds calculation logic (center, size, primary detection)
