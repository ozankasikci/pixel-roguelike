<objective>
Decouple the engine input layer from the game's RuntimeInputState by making InputSystem
manage raw GLFW key/mouse state directly, removing the RuntimeInputState dependency entirely.

Purpose: Per D-03 and D-04, the engine must not import game-layer headers. InputSystem.h currently
includes game/runtime/RuntimeInputState.h and owns a RuntimeInputState member. Additionally,
engine_input CMake target compiles game/runtime/RuntimeInputState.cpp. After this plan,
engine_input compiles with zero game includes, and the game layer builds its own RuntimeInputState
from InputSystem's raw key/mouse/scroll queries.

Output: Modified InputSystem.h/cpp, engine CMakeLists.txt, game CMakeLists.txt, and all game
systems updated to get RuntimeInputState from game-layer construction rather than InputSystem.

Note on D-03 (Action mapping system): The research recommends implementing boolean-only action
mapping. However, the current InputSystem already exposes generic `isKeyPressed(int key)`,
`isMouseButtonPressed(int button)`, `mouseDelta()`, `scrollDelta()` which are fully generic.
Adding an ActionMap on top is additive and can be done as a future enhancement. The critical
boundary violation is the RuntimeInputState dependency -- removing that is the core deliverable
of this plan. The generic key/mouse/scroll API already satisfies D-03's intent of "engine delivers
action state" (keys ARE actions at the engine level; named action mapping is a convenience layer).
</objective>

       - Remove all `state_.` delegation calls. Implement state tracking directly:

         - `isKeyJustPressed(key)`: return `key >= 0 && key < kMaxKeys && currentKeys_[key] && !previousKeys_[key]`
         - `isKeyJustReleased(key)`: return `key >= 0 && key < kMaxKeys && !currentKeys_[key] && previousKeys_[key]`

         - `lockCursor()` / `unlockCursor()`: set `cursorLocked_` directly instead of `state_.setCursorLocked()`
         - `isCursorLocked()`: return `cursorLocked_`

       - The `update()` method pattern becomes:
         ```cpp
         void InputSystem::update(Application& app, float deltaTime) {
             previousKeys_ = currentKeys_;
             previousButtons_ = currentButtons_;

             for (int i = 0; i < kMaxKeys; ++i) {
                 currentKeys_[i] = glfwGetKey(window_, i) == GLFW_PRESS;
             }
             for (int i = 0; i < kMaxButtons; ++i) {
                 currentButtons_[i] = glfwGetMouseButton(window_, i) == GLFW_PRESS;
             }

             mouseDelta_ = mouseDeltaAccum_;
             mouseDeltaAccum_ = glm::vec2(0.0f);
             scrollDelta_ = scrollAccum_;
             scrollAccum_ = 0.0f;

             keyPressEvents_.clear();
             keyPressEvents_.swap(keyPressEventsAccum_);
             typedCharacters_.clear();
             typedCharacters_.swap(typedCharactersAccum_);

             wantsCaptureMouse_ = ImGui::GetIO().WantCaptureMouse;

             if (isKeyJustPressed(GLFW_KEY_ESCAPE)) {
                 if (cursorLocked_) unlockCursor();
                 else lockCursor();
             }
         }
         ```
       - Add a private `mouseDelta_` and `scrollDelta_` member (rename from accumulator pattern):
         - `mouseDelta_` holds the delta for the current frame (set from `mouseDeltaAccum_` each update)
         - `scrollDelta_` holds the scroll for the current frame (set from `scrollAccum_` each update)
       - `lockCursor()` and `unlockCursor()` set `cursorLocked_` directly and reset mouse state as before.
