<objective>
Decouple the engine input layer from the game's RuntimeInputState by making InputSystem
manage raw GLFW key/mouse state directly, removing the RuntimeInputState dependency entirely.
Additionally, implement an ActionMap system per D-03 so games can register named actions
bound to keys/buttons.

Purpose: Per D-03, the engine provides an action mapping system where game registers named
actions ("move_forward", "attack", "interact") bound to keys/buttons and the engine delivers
action state. Per D-04, InputSystem.h must not import game-layer headers. InputSystem.h
currently includes game/runtime/RuntimeInputState.h and owns a RuntimeInputState member.
Additionally, engine_input CMake target compiles game/runtime/RuntimeInputState.cpp. After
this plan, engine_input compiles with zero game includes, the game layer builds its own
RuntimeInputState from InputSystem's raw key/mouse/scroll queries, and the ActionMap provides
named action bindings per D-03.

Output: New ActionMap.h/cpp. Modified InputSystem.h/cpp, engine CMakeLists.txt, game
CMakeLists.txt, and all game systems updated to use InputSystem directly instead of
input_.state() indirection. Game registers named actions in RuntimeGameSession.

    2. **Create `src/engine/input/ActionMap.cpp`:**
       - `bind()`: stores binding in `bindings_` map (key is `std::string(action)`)

       - `hasAction()`: returns `bindings_.count(std::string(action)) > 0`
       - `update()`: for each binding, compute pressed = any bound key pressed OR any bound mouse button pressed. Store in currentState_ (swap previousState_ first). Logic:
         ```cpp
         void ActionMap::update(const std::array<bool, 512>& currentKeys,
                                const std::array<bool, 512>& previousKeys,
                                const std::array<bool, 8>& currentButtons,
                                const std::array<bool, 8>& previousButtons) {
             previousState_ = currentState_;
             for (const auto& [name, binding] : bindings_) {
                 bool pressed = false;
                 for (int key : binding.keys) {
                     if (key >= 0 && key < 512 && currentKeys[key]) {
                         pressed = true;
                         break;
                     }
                 }
                 if (!pressed) {
                     for (int btn : binding.mouseButtons) {
                         if (btn >= 0 && btn < 8 && currentButtons[btn]) {
                             pressed = true;
                             break;
                         }
                     }
                 }
                 currentState_[name] = pressed;
             }
         }
         ```
