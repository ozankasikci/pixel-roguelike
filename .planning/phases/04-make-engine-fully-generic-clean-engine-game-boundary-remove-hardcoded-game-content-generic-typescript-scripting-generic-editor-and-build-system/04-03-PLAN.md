<objective>
Extract hardcoded player torch logic from RuntimeSceneRenderer into an ECS component+system,
and move game-specific ImGui overlay methods from engine's ImGuiLayer to a game-layer module.

Purpose: RuntimeSceneRenderer::collectLights has ~250 lines of hardcoded player torch constants,
flicker math, and 4-light computation that make the renderer game-specific. ImGuiLayer.h has
game-specific forward declarations and static methods that pollute the engine header. After this
plan, RuntimeSceneRenderer is a generic "collect all lights from ECS" loop, and ImGuiLayer is
a clean engine-only ImGui lifecycle manager.

Output: New PlayerTorchComponent, PlayerTorchSystem, GameOverlays module. Modified
RuntimeSceneRenderer, ImGuiLayer. Visual output identical to pre-refactor.
</objective>
