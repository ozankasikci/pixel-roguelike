<objective>
Decouple the engine rendering layer from the game's MaterialKind enum by replacing the
MaterialKind shadingModel field in RenderMaterialData with an opaque int shadingModelIndex.

includes game/rendering/MaterialKind.h, which violates the engine/game boundary. After this plan,
engine_rendering compiles with zero game includes, and the game layer assigns the integer value
from its own MaterialKind enum.

Output: Modified Renderer.h/cpp, MaterialTextureLibrary.h/cpp, MeshComponent.h,
RuntimeSceneRenderer.cpp. Visual rendering is pixel-identical.
</objective>
